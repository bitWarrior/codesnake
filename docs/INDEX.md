## 🤝 Contributing to Docs

When updating documentation:

1. **Keep it concise** - Users want answers fast
2. **Add examples** - Show, don't just tell
3. **Update index** - Keep this file current
4. **Check links** - Ensure cross-references work
5. **Test commands** - Verify all examples work

### Documentation Standards

- Use present tense
- Include code examples
- Add visual hierarchy (headers, bullets)
- Link to related sections
- Keep examples runnable
